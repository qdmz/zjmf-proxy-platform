# v1.0 → v1.1 升级说明

## 新增功能
1. **SMTP 邮件**：后台「系统设置 → 邮件设置」配置，发件测试一键验证
2. **注册邮箱激活**：站点设置开启后，新用户需点击邮件链接激活才能登录
3. **忘记/重置密码**：登录页「忘记密码」，邮件链接 1 小时有效
4. **登录验证码**：站点设置开启，防暴力破解（5 次失败锁定 15 分钟）
5. **公告管理**：后台发布，首页/导航展示
6. **常见问题 FAQ**：后台管理，前台 /faq 展示，客服机器人自动引用
7. **优惠券/代金券**：后台创建券码，下单时输入抵扣（固定金额 / 折扣率）
8. **在线客服**：右下角小部件，机器人自动答疑，一键转人工生成工单

## 升级步骤（约 5 分钟）

### 1. 备份（重要）
- 备份整站文件，备份数据库

### 2. 更新代码
- 解压 `zjmf-deploy-v1.1.zip`，上传覆盖到网站根目录
- **不会覆盖** `config/config.php`（包内不含该文件），现有配置保留

### 3. 升级数据库
- 进 phpMyAdmin，选中站点数据库 → 「导入」
- 选择 `database/upgrade_1.0_to_1.1.sql`（在上面的 zip 包内）→ 执行
- 看到 "导入成功" 即可

### 4. 验证
- 首页、/shop、/announcements、/faq 正常打开
- 右下角出现客服小部件
- 后台「系统设置」多出「邮件设置」分组，「内容」分组多出公告/FAQ/优惠券菜单

## 配置建议
- 邮件：QQ 邮箱用 `smtp.qq.com:587` + tls，密码填**授权码**（非登录密码）
- 先在「邮件设置」点「发送测试邮件」确认，再开启「注册需邮箱激活」
- 验证码默认关闭，需要时在「站点设置」开启

## 回滚
- 代码：恢复备份文件；数据库：本次升级只新增表/字段/设置项，不删除旧数据，
  如需回滚，删除新增的 7 张表（email_tokens/announcements/faqs/coupons/
  coupon_usages/chat_messages/login_attempts）并恢复 `users`/`orders` 的新增字段即可。
