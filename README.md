# 智简魔方代理销售平台

基于原生 PHP + MySQL 的虚拟服务器代理销售全功能平台。通过智简魔方财务系统 v1 开放 API 对接上游供货商，实现产品同步、加价销售、自动开通、实例管理、续费退订。

演示站：https://qdmz.web1337.net/

## 功能清单

### 前台（用户）
- 首页 / 产品商城（按类型、分组筛选）
- 产品详情：周期选择、配置项选择、实时计价、下单
- 下单页优惠券验证（实时显示立减/实付金额）
- 收银台：余额支付 / 易支付（支付宝/微信/QQ）
- 账户充值、余额明细
- 控制台：我的服务器列表（仅显示已开通）
- 实例管理：开机/关机/重启/强制操作、重置密码、重装系统（含密码设置）、VNC 控制台（本站/上游双链接可切换）、自动续费开关、同步实例信息、刷新电源状态
- 实例详情：IP、配置快照（CPU/内存/带宽/节点等）、到期时间
- 续费（支持优惠券抵扣，生成续费账单并自动向上游续费）、退订（立即删除/到期删除）
- 站内消息、工单系统、用户注册/登录（含邮箱激活、验证码、登录锁定）
- 公告、FAQ、在线客服小部件

### 后台（管理）
- 仪表盘：用户/产品/实例/收入统计、近 7 天收入图表、最新订单
- 上游供货商：添加/编辑/删除、测试连接、一键同步产品、上游接口日志（含完整请求/返回 JSON 查看）
- 产品管理：筛选、上架/下架、改名、加价策略、手动调价、一键重新应用加价、分组管理
- 订单管理：筛选、详情、开通失败重试、标记人工处理、退款到余额
- 实例管理：筛选、详情、从上游同步
- 用户管理：搜索、启用/禁用、余额手动调整、添加管理员
- 财务：账单记录（筛选+收入统计）、管理员操作日志
- 优惠券管理：创建/编辑/发放、使用记录
- 工单管理：回复工单、可关闭工单
- 公告/FAQ 管理
- 系统设置：站点设置、SMTP 邮件、易支付配置、到期提醒天数

### 定时任务（cron/）
- `sync_hosts.php`：每 5 分钟同步实例状态
- `expire_check.php`：每天到期检查 + 续费提醒
- `sync_products.php`：每天同步上游产品价格

## 快速开始

详见 [docs/DEPLOY.md](docs/DEPLOY.md)。

1. 将代码上传到服务器，Web 根目录指向 `public/`
2. 浏览器访问 `http(s)://你的域名/install.php` 按向导完成安装
3. **删除 `public/install.php`**
4. 登录后台 `/admin` → 上游供货商 → 添加上游 → 测试连接 → 同步产品
5. 审核产品价格后上架
6. 配置 cron 定时任务（见部署文档）

## 重要说明

- 上游账单由**供货商 API 账号余额**支付：用户付款进入平台账户，开通时从上游账号余额扣款。请保持上游账号余额充足。
- 新同步的产品默认**下架**，需管理员审核价格后手动上架。
- 上游余额支付状态码：1001=全额支付成功并开通；200+“Successful use of balance”=部分抵扣仍有尾款；400=余额不足。
- 上游库存以 V1 `cart_add` 返回的 "Inventory shortage" 为准，公开目录接口的库存字段不准。
- API 依据为第三方整理的魔方财务 3.5.8 契约，不同版本可能存在字段差异，务必用真实上游环境联调。
